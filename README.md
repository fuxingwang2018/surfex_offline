Run SURFEX offline.
1. Clone to your local git clone https://git.smhi.se/fuxing.wang/surfex_offline.git surfex_offline
2. Description of each directory:
  SURFEX_FORCING: Create SURFEX format netcdf forcing. It will be added later.
  SURFEX_COMPILE: Compile SURFEX code
  SURFEX_RUN: Run SURFEX simulations
  SURFEX_DIM_Convert: Convert SURFEX original 1D output 1D (grid points) to 2D (x and y map)
3. History: git add "file_to_add" git commit -m "write comments here"; git push -u origin master
